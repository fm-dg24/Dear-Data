# Dear-Data
This repository documents my progress on the Dear Data assignment for Creative Coding.
## Project goals:
- Explore personal data through observation and collection.
- Develop ideas for representing data visually.
- Experiment with creative coding in Processing.
- Document my progress throughout the project.
## Progress log:
- Created the project folder and outlined the aims of the assignment.
- Created Dear data data collection csv.
- Created 100 columns for each data item, and rows including sound, location, loudness(1-10), and type.
- Collected 57 data items
- Added the completed version of the sound data collection with all 100 data  items.
- Began designing and planning how data can be represented

## Design plan:
### Initial design
Represent the sound using 100 fixed spaced out shapes, have each sound represent different categories by the different geometry of each shape, and loudness by size of each shape. The colour of each shape can represent the location of the sound (indoor or outdoor).

### 2nd design
Have all 100 sounds represented as lines forming the shape of a sound wave. Have each portion of the wave be a line where each line represents 1 data item. The sound will continuously loop from left to right to create a visual of the sound wave moving. There will be buttons that the viewer can press that will change the lines on the waves colour based on their category, either sound type or location.
